# Model logos

Selected SVGs from [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/34270bc208d7122778dc00b30bd460f97ea03216/packages/static-svg/icons), pinned to `34270bc208d7122778dc00b30bd460f97ea03216`. MIT license included in LICENSE. Brand marks belong to their respective owners; these marks identify model authors, without implying endorsement.

Assets are bundled locally, with no CDN requests or runtime package. Color variants (`*-color.svg` upstream, saved under the brand filename here) are preferred. OpenAI, Anthropic and Grok have monochrome marks, displayed white on the dark UI. Add mappings in `app/lib/model-brand.ts`.
